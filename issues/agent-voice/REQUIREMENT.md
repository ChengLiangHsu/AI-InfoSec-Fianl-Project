# 需求規格書：新增 AI Agent 語音功能

## 1. 背景與目標 (Background & Goals)
- **核心問題**：目前無人機影像分析平台中的 AI 助理 (`AskAgent.vue`) 僅支援純文字輸入與閱讀，在巡檢現場或雙手操作滑鼠檢視圖資時，文字輸入較不便利。
- **改動目標**：引入語音輸入 (STT) 與語音朗讀 (TTS) 雙向語音互動能力，實現點擊說話自動辨識發送、AI 回覆自動朗讀與手動控制，提升使用者人機互動體驗。

## 2. 功能範圍 (Scope)
- **包含項目 (In Scope)**：
  - 前端整合瀏覽器原生 Web Speech API (`SpeechRecognition` / `webkitSpeechRecognition` 與 `window.speechSynthesis`)。
  - 語音輸入 (STT)：輸入列提供麥克風控制按鈕與錄音中視覺動畫（閃爍/呼吸燈）。
  - 自動發送機制：說話結束後偵測停頓（約 1.5 秒無語音）自動送出對話。
  - 自動與手動朗讀 (TTS)：AI 回覆生成完畢後自動觸發語音朗讀；每則 AI 訊息旁提供手動播放/停止朗讀按鈕。
  - 語音打斷 (Barge-in)：點擊開啟麥克風時，若 AI 正在朗讀則立即中斷 TTS 播放。
- **排除項目 (Out of Scope)**：
  - 後端音訊串流伺服器與第三方雲端 STT/TTS API（如 OpenAI Realtime API、Whisper API）。
  - 語音自訂音色模型訓練或聲音複製。

## 3. 決策歷程與討論紀錄 (Key Decisions & Rationale)
- **架構選型**：採用瀏覽器原生 Web Speech API。無需增加後端音訊傳輸負載與雲端 API 額外計費成本，具備最低延遲與輕量化優勢。
- **操作流程**：採「自動發送模式」。點擊開始辨識，辨識完成後自動送出，搭配 AI 回應後自動朗讀，打造連貫的語音對話體驗。
- **語音中斷機制**：支援「智慧打斷與回音防護」。開啟麥克風時強制停止當前朗讀，防止電腦喇叭聲音被收音導致回音污染。
- **語言偏好**：固定設定為繁體中文 (`zh-TW`)。

## 4. 邊界條件與例外處理 (Edge Cases & Error Handling)
- **無效/空白語音**：若使用者未說話或僅有微弱環境雜音導致未辨識出有效字詞，自動取消發送並重置錄音狀態，不送出空字串。
- **麥克風權限被拒/無硬體設備**：攔截 `not-allowed` / `audio-capture` 錯誤，將麥克風按鈕置灰，並提供 Tooltip 提示「無法取得麥克風權限」。
- **瀏覽器不支援 Web Speech**：在不支援的瀏覽器環境中優雅降級，隱藏或禁用語音按鈕，完全不影響原有的文字對話功能。
- **串流中斷或重試**：當使用者手動點擊停止錄音或切換對話時，即時銷毀語音辨識實例與合成佇列，避免音訊殘留或背景持續監聽。

## 5. 非功能性需求 (Non-Functional Requirements)
- **語言支援**：STT 與 TTS 預設指定 `zh-TW`。
- **UI 響應性**：錄音狀態與朗讀狀態具備清晰視覺反饋（如麥克風圖示亮起/波紋、播放中動畫圖示）。
- **向後相容**：維持既有文字輸入與訊息呈現不受任何破壞，不修改現有後端 API 協定。

## 6. 驗收準則 (Acceptance Criteria)
- [ ] 驗收條件 1：點擊麥克風按鈕可啟動語音辨識，辨識結果能自動帶入並於停頓後自動發送給 AI Agent。
- [ ] 驗收條件 2：AI 回覆完成後自動朗讀內容；使用者隨時可透過訊息旁按鈕手動停止或重新朗讀。
- [ ] 驗收條件 3：當 AI 正在朗讀時點擊麥克風，系統能立即中斷朗讀並進入錄音辨識。
- [ ] 驗收條件 4：辨識為空或未獲取麥克風權限時，有友善防護與降級提示，純文字對話功能維持正常。
