# Domain Docs

Before exploring the codebase, read:

- `GLOSSARY.md`, if present.
- `GLOSSARY-MAP.md`, if present.
- Relevant ADRs under `docs/adr/`.

Missing domain documents are not errors. The domain-modeling workflow creates them when needed.

## Layout

This repository uses the single-context layout:

```text
/
├── GLOSSARY.md
├── docs/adr/
└── src/
```

Use terminology defined in the glossary. Explicitly report any conflict with an existing ADR.
