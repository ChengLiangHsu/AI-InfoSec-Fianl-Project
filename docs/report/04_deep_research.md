# 4. Deep Research: 三大核心問題

> 領域定義：作物保護田間藥效試驗 + UAV 遙測評估。

### Q1. 五個核心思維模式

| # | 思維模式 | 意義 | 證據 | 對系統設計的影響 |
| :---: | :--- | :--- | :--- | :--- |
| **1** | **對照組決定一切<br>(UTC first)** | 藥效不是「處理後有多好」，而是「相對未處理對照 (UTC) 好多少」；UTC 壓力不足，整場試驗無效 | Abbott、Henderson-Tilton 公式皆以 UTC 為分母；EPPO PP 1/152 要求檢核對照區的病蟲草壓力 [18] | Agent 第一步先讀 UTC 小區指標，壓力低於門檻即輸出「試驗無效」而非硬算防治率 |
| **2** | **重複與區集吸收變異** | RCBD 用區集吸收田間梯度（水位、土壤、光照），重複用來估誤差；單一小區的數字沒有意義 | 4RL 試驗 3 區集 $\times$ 8 處理；Bayer 以 CV 檢核試驗可信度，CV 範圍依作物/目標不同 [18] | 分析單位固定為「小區 $\rightarrow$ 處理平均 $\pm\text{ SE}$」，並計算 CV、做 ANOVA；區集效應顯著時要報告 |
| **3** | **時間序列比單點重要** | 藥效隨 DAA 變化（速效/持效），一次飛行只能看到一個切片；殘效期與再發是審查重點 | 4RL 捲葉率調查 $0 \sim 50\text{ DAA}$ 共 10 時點；DPI 試驗多次飛行追蹤 [15]；多時相 UAV 可提早偵測白葉枯病 [10] | 影像必須以 DAA 對齊 ground truth；agent 推理時明確標示「本結論基於 42 DAA 單次影像」 |
| **4** | **先排除干擾，再談指標** | 植生指標對非目標綠色（青苔、藻類、鄰區飄移、陰影）同樣敏感；指標上升不等於雜草多 | Concil 試驗青苔抬高 VARI；SAM 會把雜草與土壤一併分割 [7]；本組以 ExG-brightness 分離育苗箱與雜草 | 工具鏈中「干擾遮罩」先於「指標計算」；多光譜 (NDRE) 作為交叉驗證 |
| **5** | **可重現、可追溯、可審查** | 登記報告會被審查員逐項質問；任何數字都要能回到原始小區、原始方法 | TACTRI 報告格式要求處理/重複/時點/統計；評分者偏差可量化 [12] | 每條結論附 ROI 影像、指標值、公式、規範條文；agent 不得輸出無來源的判斷 |

### Q2. 三個最重要的專業爭論

#### 爭論 1：UAV 影像指標能否取代人工目測評分？
* **觀點 A（可取代）**：UAV 指標比目測更精確、更一致 [13, 14]；DPI 多次飛行顯示地面與空中評估在多數處理上高度相關 [15]。
* **觀點 B（只能補強）**：目測能整合「株勢 + 數量」等指標無法捕捉的資訊；Willard (1958) 早指出單純計數可能誤判除草劑效果；登記準則目前仍要求人工調查。
* **Evidence**：相關係數多在 $0.7 \sim 0.9$，但依目標而異（雜草覆蓋度高、捲葉率中等、株內害蟲低）。
* **Consensus**：UAV 適合「覆蓋度/面積型」目標，可作為輔助與交叉驗證。
* **Unresolved**：株內/葉背害蟲（如二化螟幼蟲）影像幾乎無法直接看見，只能從次級症狀（枯心、白穗）推估；法規尚未接受影像作為主要評估方法。

#### 爭論 2：RGB 高解析度 vs. 多光譜 / 高光譜？
* **觀點 A（RGB 足夠）**：$< 1\text{ cm}$ GSD 的 RGB 已能分辨個別雜草與捲葉紋理；成本低、飛行簡單；VARI、ExG 等 RGB 指標在多數試驗表現良好 [14]。
* **觀點 B（需多光譜）**：RGB 對葉綠素含量與水分脅迫不敏感；青苔/藻類會混淆 RGB 指標；NDRE / 高光譜能分離 [11, 22]。
* **Evidence**：本組 Concil 試驗中 VARI 受青苔抬高、NDRE 區分較佳；WeedsGalore 提供 RGB + RE + NIR 供比較 [8]。
* **Consensus**：RGB 做「幾何/紋理」（計數、分割、覆蓋度），多光譜做「生理」（脅迫、葉綠素）；兩者互補。
* **Unresolved**：在成本限制下，何種目標非用多光譜不可？多光譜影像的小區級校正（反射率板、光照）在小型試驗仍不穩定。

#### 爭論 3：通用 VLM / Foundation Model vs. 任務專用模型 + 規則？
* **觀點 A（Foundation Model）**：SAM 2.1 zero-shot 免標註 [7, 20]；VLM 可給語言化推理與自我修正 [3]；維護成本低、可泛化。
* **觀點 B（專用模型 + 規則）**：AgroBench 顯示開源 VLM 雜草辨識近隨機 [1]；MLLM 有 ground-level bias [5]；YOLO-seg 微調後精度高且可量化 [6]；規則（公式、CV 門檻）必須確定性執行，不能交給 LLM 推估。
* **Evidence**：AgriDoctor 的結果顯示「領域適配 + 模組化」優於單一通用模型 [2]。
* **Consensus**：LLM 當 planner / 整合者，感知與計算交給專用工具——這正是本專題的架構選擇。
* **Unresolved**：VLM 的幻覺如何在高風險（登記）情境下被保證攔截？人類在迴圈的最小必要介入點在哪？

### Q3. 十個深度理解問題

| # | 類型 | 問題 |
| :---: | :--- | :--- |
| **1** | Why | 為什麼藥效公式一定以 UTC 為分母？如果 UTC 小區被青苔覆蓋導致 VARI 偏高，整場試驗的防治率會往哪個方向偏？ |
| **2** | What-if | 若 4RL 的三個區集位於水位由高到低的梯度上，且只有第 III 區集有白穗，ANOVA 會告訴你什麼？Agent 應如何回報？ |
| **3** | Trade-off | 飛行高度 $20\text{ m}$（$\text{GSD } 0.5\text{ cm}$）與 $40\text{ m}$（$\text{GSD } 1\text{ cm}$）之間，對雜草分割 mIoU、每架次覆蓋面積、正射拼接錯誤率各有何影響？你會為除草劑試驗選哪個？ |
| **4** | Failure Case | 42 DAA 時縱捲葉蟲捲葉已枯黃，與缺氮黃化在 RGB 上如何區分？若無法區分，agent 應輸出什麼？ |
| **5** | Evidence | 一個處理的影像指標比 UTC 低 30%，但人工捲葉率只低 10%，你會相信哪個？需要哪些額外證據才能下結論？ |
| **6** | Comparison | VARI、ExG、NDRE 三者在「水田有青苔」情境下，對雜草覆蓋度的敏感度排序為何？為什麼？ |
| **7** | Design Decision | 為什麼小區切割要加 $1\text{ m}$ 外緣 buffer 再做模板比對，而不是直接在原始多邊形內計算？不加會發生什麼？ |
| **8** | Design Decision | 為何 LLM 不應直接計算防治率，而是呼叫確定性的統計工具？若 LLM 算錯一個小數點，在登記審查中會有什麼後果？ |
| **9** | Real-world Scenario | 審查員問：「你的影像結論與人工調查結論不一致，以哪個為準？」依 TACTRI 準則與本系統設計，你如何回答？ |
| **10** | Failure Case | SAM 2.1 把相鄰兩個小區的雜草團塊切成同一個 instance，下游的處理平均會如何被污染？系統在哪一層應該攔截？ |
