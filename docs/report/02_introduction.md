# 2. Introduction 緒論

> **Why is this project worth doing?**  
> 田間藥效試驗是每一個農藥產品上市前的法定門檻，但其核心資料——小區評分——仍是整條流程中最主觀、最難重現的一環。高解析度 UAV 影像與可推理的 AI Agent 已經成熟到可以把這一環變成「有證據、可追溯、可重算」的資料。

### A. Attention Getter
* 全球農業無人機市場 2024 年約 USD 27 億，預估 2033 年達 USD 319 億（CAGR 28%）[16]；美國噴藥無人機處理面積 2024–2025 年由 1,030 萬英畝增至 1,640 萬英畝 [17]。無人機在田間已是常態設備，影像資料正大量產生。
* 2025 年是「農業 VLM 元年」：AgroBench (ICCV 2025) [1]、AgroMind [4]、AgriDoctor [2]、AgroOmni (2026) [5] 在一年內相繼發表，從 benchmark 到 agent 架構皆已成形。
* 然而 AgroBench 的評測顯示，多數開源 VLM 在雜草辨識任務上表現接近隨機 [1]——通用模型「看得到」但「看不懂」農業影像，正是領域 agent 的切入點。

### B. Background
* **應用領域**：作物保護（CP）產品的田間藥效試驗。Bayer 全球每年約 2 萬場 [18]；在台灣，新農藥登記須依 TACTRI（農業部農業藥物試驗所）準則完成田間藥效試驗並提交報告。
* **使用者**：試驗執行者（如 Bayer 產品開發 / 技術人員）、委託試驗機構（CRO、農改場）、審查人員。
* **技術背景**：消費級多旋翼機（如 DJI M4E）在 $20 \sim 30\text{ m}$ 高度可取得 $\text{GSD} < 1\text{ cm}$ 的 RGB 正射影像，並可搭載多光譜（NDRE）；DroneDeploy / Pix4D 可輸出 GeoTIFF + GeoJSON 小區界線；SAM 2.1 [7]、YOLO-seg [6] 提供 zero-shot / 少量標註的分割能力；LLM 提供工具呼叫、知識檢索與報告生成。

### C. Problem
如何將一張高解析度 UAV 正射影像 + 試驗設計檔，自動轉成每一小區、每一處理、每一調查時點的藥效證據，並依據登記試驗規範推理出可提交的結論？具體子問題：
1. **小區級證據抽取**：在 $< 1\text{ cm}$ GSD 下，如何穩定分離目標（雜草、病斑、捲葉、白穗）與干擾（青苔、水面反光、陰影、相鄰小區）？
2. **領域規則整合**：如何把 RCBD 設計、處理代碼、DAA 時點、Abbott / Henderson-Tilton 公式、藥害分級等規則，變成 agent 可查詢、可執行的知識？
3. **可驗證輸出**：結論必須能回溯到影像區域、指標數值與引用規範，而非 LLM 的自由發揮。

### D. Existing Limitations

| 現有做法 | 限制 | 證據 |
| :--- | :--- | :--- |
| **人工目測評分** | 受評分者嚴格度、疲勞、走動順序影響；跨人跨地難比較 | [12] |
| **UAV 單一植生指標（NDVI / VARI）** | 青苔、水面、土壤背景會抬高指標；僅做一次相關分析，不處理試驗設計 | 本組 Concil 試驗觀察；[19] |
| **任務專用深度學習模型（YOLO / U-Net）** | 需大量標註、跨田區泛化差、無法解釋 | [3, 6, 8] |
| **通用 VLM 直接讀圖** | 雜草辨識近乎隨機 [1]；UAV 尺度有 ground-level bias [5]；缺少試驗設計與藥效公式概念 | [1, 3, 5] |
| **農業 Agent（AgriDoctor 等）** | 以單株近拍 + 病害名稱為主，未處理小區 / 處理 / 重複的試驗結構 | [2] |

### E. Innovation
1. **試驗設計即輸入**：Agent 直接讀取 GeoJSON 小區界線與處理表，推理時知道「哪個小區是 UTC、哪個是 T5 第 2 重複」，而非只看一張圖。
2. **工具化的領域分析鏈**：把本組已驗證的影像方法（ExG-brightness 分離雜草與育苗箱、兩方向模板比對、ROI 排除干擾、NDRE 對青苔的區分）封裝成 agent 可呼叫的 tools，而非 LLM 自行「看圖說話」。
3. **規範驅動的推理**：RAG 知識庫收錄 TACTRI 準則、EPPO PP 1/152 設計與分析規範、藥效公式與 CV 門檻，agent 在產生結論前先檢核試驗是否有效（CV、UTC 壓力、重複一致性）。
4. **可追溯輸出**：每一條結論附影像 ROI、指標數值、統計結果與引用條文；符合「教師可針對結果口頭提問」與登記審查的要求。

### F. Contributions
* **C1.** 一個可實作的 Domain AI Agent 架構，將 UAV 正射影像 + 試驗設計 $\rightarrow$ 小區級證據 $\rightarrow$ 藥效評估報告草稿。
* **C2.** 一組針對 $< 1\text{ cm}$ GSD 田間試驗影像的分析工具集（小區切割、指標計算、干擾排除、分割），以兩個真實試驗（4RL、Concil）驗證。
* **C3.** 一個整合 TACTRI/EPPO 規範與藥效公式的領域知識庫與 pseudocode 推理流程。
* **C4.** 一套評估協定：影像指標 vs. 人工 ground truth、處理排序一致性、與通用 VLM baseline 的比較、agent 回答可追溯性評分。
* **C5.** 公開的 GitHub repository 與 `DESIGN.md`，使他人可重現並延伸至其他作物與目標（病害、藥害、倒伏）。
